# GirisimciBulmaPlatformu

GirisimciBulmaPlatformu, fikri veya projesi olan ve ortak arayan kişilerin, çok detay vermeden ilan yayınlayabildiği bir ortak bulma platformudur. İlanı incelemek isteyen kullanıcılar, gizlilik ve güven için sözleşmeyi onayladıktan sonra detayları görebilir.

## Amaç ve İşleyiş
- Proje/fikir sahipleri özet bilgilerle ilan oluşturur.
- İlgilenen kullanıcılar sözleşme onayı sonrası ayrıntılı inceleme yapabilir.
- Ortaklık arayanları ve doğru eşleşmeyi hızlandırmayı hedefler.

## Öne Çıkan Özellikler
- Kullanıcı kayıt ve giriş akışı
- İlan yayımlama ve listeleme
- Sözleşme onayı ile detayların açılması
- Component tabanlı kullanıcı arayüzü

## Kullanılan Teknolojiler
- C# ve .NET 6
- Blazor WebAssembly (Client) ve ASP.NET Core (Server)
- Component tabanlı UI (DevExpress Blazor)
- MSSQL ve Entity Framework Core
- HTML, CSS ve JavaScript
- Blazored.SessionStorage

## Proje Yapısı
- **GirisimciBulmaPlatform.Client**: Blazor WebAssembly istemci uygulaması
- **GirisimciBulmaPlatform.Server**: ASP.NET Core sunucu katmanı
- **GirisimciBulmaPlatform.Shared**: Ortak modeller ve paylaşılan yapı
- **assets**: Ekran görüntüleri
